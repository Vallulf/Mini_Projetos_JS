# 🚀 Mini Projetos — Prática de Desenvolvimento

Repositório criado para armazenar meus **mini projetos de programação**, desenvolvidos durante meus estudos e prática de desenvolvimento web.

O objetivo é colocar em prática conceitos de **HTML, CSS, JavaScript, Node.js, Supabase e APIs**, evoluindo gradualmente para projetos mais completos.

---

## 📚 Projetos

### 🧮 1. Calculadora de IMC

Calculadora que permite informar peso e altura e calcular o **Índice de Massa Corporal (IMC)**.

**Conceitos praticados:**

* HTML
* CSS
* JavaScript
* Manipulação do DOM
* Eventos
* Funções
* Condicionais
* Operações matemáticas

---

### 👤 2. Sistema de Cadastro

Mini sistema de cadastro de clientes utilizando formulário e operações de CRUD.

**Funcionalidades:**

* Cadastrar cliente
* Listar clientes
* Editar cliente
* Excluir cliente

**Conceitos praticados:**

* JavaScript
* DOM
* Arrays e objetos
* `forEach()`
* Funções assíncronas
* `async/await`
* CRUD
* Integração com banco de dados

---

### ⚡ 3. CRUD com Node.js + Supabase

Projeto desenvolvido para praticar a criação de um **backend utilizando Node.js**, conectado ao banco de dados do Supabase.

**Tecnologias:**

* Node.js
* Express
* JavaScript / TypeScript
* Supabase
* PostgreSQL
* API REST

**Conceitos praticados:**

* Backend
* Rotas
* Requisições HTTP
* API REST
* CRUD
* Banco de dados
* Integração entre frontend e backend
* Variáveis de ambiente
